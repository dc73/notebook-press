# Notebook Press identity

The logo combines a geometric **N** with folded book pages. Ivory and sage sit on a forest green field, matching the desktop interface.

- Original: [`logo.png`](../notebook_press/assets/logo.png)
- Windows: [`app.ico`](../notebook_press/assets/app.ico)
- macOS: [`app.icns`](../notebook_press/assets/app.icns)
- Desktop interface: [`icon-64.png`](../notebook_press/assets/icon-64.png)

The original logo was generated with the built-in image-generation tool. Native icon sizes are encoded from that image with `python scripts/make_icons.py`.

## Generation prompt

> Design a professional minimalist app logo for Notebook Press. One square icon, completely flat 2D vector style. Entire canvas is a perfectly uniform solid deep forest green #202D2A. Center a bold custom ivory #F4F3EE geometric N monogram constructed from two upright book-page shapes connected by a strong diagonal page fold. One small restrained sage #C7DDBA folded-page accent. The icon should feel like a beautifully designed publishing utility: precise, intelligent, quiet, Swiss modernist. Strong compact silhouette, clean generous negative space, very few simple geometric shapes, distinctive at 24 pixels. The monogram occupies about 60 percent of the canvas. All fills perfectly flat and opaque. NO rounded-square container within the image, NO open-book illustration, NO arrows, NO extra text, NO watermark, NO gradients, NO textures, NO grain, NO lighting, NO shadows, NO 3D, NO mockup. Clean finished brand mark, not a presentation board.
